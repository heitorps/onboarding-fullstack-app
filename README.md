# Descrição Geral
O aplicativo sugerido para o onboarding consiste em registrar usuários para fazer reviews de álbuns.

Um usuário se cadastra e pode registrar, ver, atualizar e excluir suas reviews, além de seguir outros usuários para ver suas reviews na timeline principal do projeto.

As reviews consistem na imagem da capa e nome do álbum, imagem e nome do artista e ano de lançamento, seguidos por uma nota de 0 a 10, um texto avaliando o álbum e uma tabela com as músicas do álbum avaliadas enumeradamente (NO REVIEW, SKIT, BAD, MID, GOOD, AMAZING, PERFECT).
